# Certificate image import
The 13 records in certificateRecords were transcribed from original photographs supplied by the owner. Undated records omit period. Images are expected as WebP files in public/documents/ with exact filenames in data.ts. The server includes each record only once its file exists in the build; no broken image placeholders. Upload the prepared 13 WebP images to public/documents/ on this branch, then deploy. Images have orientation corrected and preserve the full document; no generated or altered award text. Review public exposure of names, stamps and signatures before production release.
