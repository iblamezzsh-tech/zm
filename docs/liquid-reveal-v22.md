# V22 — Velocity-driven fluid reveal
The owner approved the skaffa/lando-effect demo with slightly slower movement. Its public README describes a velocity-based Navier–Stokes effect. This iteration implements an original CPU semi-Lagrangian velocity transport, pressure projection, vorticity confinement, and velocity-derived alpha; it does not vendor the GPL demo or its shaders. The previous wave/ink brush is removed. Slower transport (.72), mild momentum decay (.969), directional thresholding and recurring figure-eight idle movement are chosen for a calmer aesthetic. Existing portrait alignment, full toggle, pause, reduced motion, typography and full-bleed composition remain. Browser performance and aesthetic match require visual testing; preview only.
