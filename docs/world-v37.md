V37 replaces the prior screen-space contour effect with a perspective 3D world. Original procedural triangle meshes, shaded solid sculpture, terrain and architecture are fixed in world coordinates. A scroll-controlled camera moves along the negative Z axis, with camera basis, perspective projection, depth testing and fog. Canvas fallback projects the same triangles, clips near plane and depth sorts them. The existing original document images remain accessible HTML, not fabricated certificate textures. The approved hero, project exhibition, navigation and page transitions are unchanged. Preview only; GPU availability and visual acceptance require real-browser verification.
