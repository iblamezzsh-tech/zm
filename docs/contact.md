# Public contact configuration
The portfolio contact page uses NEXT_PUBLIC_CONTACT_EMAIL only if a syntactically valid address is explicitly configured. Set it to an owner-approved public email in Vercel's project environment settings and redeploy. This address will be visible to visitors. There is no message storage, fake submission success, or unconfigured backend. Until an email is configured, the page honestly displays that direct contact details are coming soon and provides links to the known project website and portfolio repository. No unconfirmed Telegram, LinkedIn, telephone or email details have been published.
