# V39 — One continuous film
Replaces the homepage's previous pinned sections, per user feedback. A single full-viewport projection contains all ten chapters in one shared CSS 3D world. Scroll maps to one GSAP master timeline; its camera travels on a Catmull–Rom lateral/vertical spline and continuous forward depth axis. Lenis supplies smooth native scroll. A procedurally authored metallic ribbon uses the identical camera projection in WebGL, with a CPU Canvas fallback. The portrait at zero progress is the approved original, then opens as a moving aperture. No slide deck, snap, hold timers, independent pinning or frozen card boxes. The full viewport itself remains the camera surface while the world moves through it. Original certificate images, project data, route links and signature preserved. Desktop enhanced, touch/reduced-motion and manual read mode use ordinary document flow. Interior routes retain existing design and motion; production remains V31.
