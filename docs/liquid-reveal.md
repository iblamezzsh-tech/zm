# V21 — liquid reveal
Replace the circular CSS mask with a low-resolution damped wave simulation and transported alpha density. Cursor velocity stretches irregular deposits; ink trails diffuse and dissolve; waves travel outward and deform the background contours through the same shared field. The attire is composited on a canvas inside the shared scaled portrait plane, maintaining face registration. Full present/future toggle, touch, pause, reduced motion, hidden tab and offscreen handling remain. The initial automatic sweep uses the same field. This is a custom 2D wave approximation, not a claim to reproduce the reference site's proprietary shader. Browser verification of visual quality, performance and image alignment is required.
